# Para downloads

[Download the latest Para release](https://github.com/zenzen-sol/para-releases/releases/latest)

Para is currently available for Apple Silicon Macs (M1 and later).

1. Download the `.dmg` installer from the latest release.
2. Open it and drag Para into Applications.
3. Launch Para from Applications.

Para checks for signed updates when it starts. You can also use **Para → Check for Updates…**. Updates are offered for confirmation, back up application data, install, and restart the app. If you have an earlier development build without the updater, install this release once to begin receiving updates.

Installers are signed with Developer ID and notarized by Apple. Releases include the signed updater archive, its signature, update metadata, and SHA256 checksums. This repository contains release artifacts; the source and build pipeline are private.
